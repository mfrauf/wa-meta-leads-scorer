Why no "remove from pool"

  • • Meta custom audiences are append-only
  • • You never delete a member via API
  • • Membership expires via the retention window (e.g. 30 days since last event)
  • • So "movement" is simulated with exclusions, not edits

How someone "moves" cold → hot

  • • First chat scores warm → fires LeadWarm once
  • • Later replies score hot → fires LeadHot once
  • • They now sit in BOTH Warm and Hot pools
  • • Campaign B excludes Hot → they stop seeing B, start seeing C
